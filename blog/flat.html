1:1 colors in blender

here's a guide on how to make limited palette / flat color / low poly renders with blender that output the exact colors in your textures

blender's defaults are aimed at more realistic styles so it has a bunch of modern utilities turned on

Resolution

first, set your render resolution to some lower value

Samples

set samples to 0 (there's no reason to sample a lot if you're going for an aliased look) and turn off temporal reprojection

Filter size

set filter size to 0 (though setting samples to 0 should still get rid of antialiasing)

Dither

turn off dither. i had issues with this one before because if you work with flat color models the dither only gets applied after you save the render. this in turn introduces noise in what you thought would be a render with a very limited color palette

Tonemapper

switch view to Standard. this basically turns off the tonemapper (aka the thing that prevents blown out colors and makes realistic renders look better but skews your colors ever so slightly)

I recommend using File > Defaults > Save Startup File to set this as your default file if you make low poly / retro things often
